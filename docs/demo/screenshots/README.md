# Screenshots

Screenshots of the live platform for the datathon submission and slide deck.

## How to capture

1. Open the live Vercel URL in Chrome/Safari at 1440px width, zoom 90%
2. Use full-page screenshot or window screenshot (Command+Shift+4 on Mac)
3. Make sure the Vercel URL is visible in the browser address bar
