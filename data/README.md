# Data Directory

This directory contains all data files for the KCTCS Student Success Prediction project.

## 📁 File Descriptions

### Source Data Files

| File | Description | Records | Size |
|------|-------------|---------|------|
| `De-identified PDP AR Files.xlsx` | Original Excel file with AR data | ~20K | 4 MB |
| `ar_kcts_with_zip.csv` | AR data with zip codes added | ~20K | 2 MB |
| `kctcs_cohorts_with_zip.csv` | Student cohort data with zip codes | ~20K | 7 MB |
| `kctcs_courses.csv` | Course enrollment records | ~500K | 29 MB |

### Processed Data Files

| File | Description | Records | Size |
|------|-------------|---------|------|
| `kctcs_merged_with_zip.csv` | Merged dataset (cohorts + AR + courses) | ~500K | 52 MB |
| `kctcs_student_level_with_zip.csv` | Student-level aggregated data | ~20K | 12 MB |

### Output Files (Generated by ML Pipeline)

| File | Description | Records | Size |
|------|-------------|---------|------|
| `kctcs_student_level_with_predictions.csv` | Student-level data with ML predictions | ~20K | 17 MB |
| `kctcs_merged_with_predictions.csv` | Course-level data with ML predictions | ~500K | 72 MB |

## 📊 Data Schema

### Key Identifier
- **`Student_GUID`**: Unique student identifier used across all files

### Data Relationships

```
kctcs_cohorts_with_zip.csv (1 row per student)
    ├── Merged with → ar_kcts_with_zip.csv (1 row per student)
    └── Merged with → kctcs_courses.csv (multiple rows per student)
         └── Results in → kctcs_merged_with_zip.csv (1 row per course enrollment)
              └── Aggregated to → kctcs_student_level_with_zip.csv (1 row per student)
                   └── ML Pipeline adds predictions → kctcs_student_level_with_predictions.csv
                        └── Predictions merged back → kctcs_merged_with_predictions.csv
```

## 🔄 Data Processing Workflow

1. **Source Files**: Start with raw CSV and Excel files
2. **Merge**: Run `merge_kctcs_data.py` to create merged dataset
3. **Aggregate**: Create student-level aggregated features
4. **ML Pipeline**: Run `complete_ml_pipeline.py` to generate predictions
5. **Output**: Predictions saved to both student-level and course-level files

## 📝 Notes

- All student data is de-identified
- Missing values are handled during preprocessing
- Zip codes added for geographic analysis
- Course-level data includes one row per course enrollment per student
- Student-level data aggregates all courses into summary statistics

## 🔒 Data Privacy

All data files contain de-identified student information. No personally identifiable information (PII) is included.
